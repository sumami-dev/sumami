## The memory budget

Two tiers, the whole process's resident set against the ceiling the product
promises. The **exact** peak is read from `/proc/self/status` (VmHWM) — that is
Linux only; elsewhere the number is the highest value a sampler saw, which is
a lower bound.

```
$ cargo run --release --example memory_budget -p sumimi-service -- --engine 128MB
engine=128MB threads=2 events=200000 flushes=41 flush p50=20ms p99=119ms max=119ms engine_holds=7 MB peak_rss=n/a peak_sampled=176 MB disk=8.3 MB dropped=0
no exact peak RSS on this platform — run it on Linux to assert the budget
```
